# Agent Nexus 1.0.0-beta.1

2026-10-16，首个 GitHub 1.0 测试版，标记为 Pre-release。用于个人使用与反馈，尚非稳定版。

## 本版内容

包含本地项目、原生 Codex / DSH 任务、Leader 与团队、独立审查和有限返工、会议、Model Hub、可视化工作流、历史搜索/回放及脱敏诊断。

修复普通 Windows 启动环境下 Codex CLI 漏检：PATH 优先，并补查已有 OpenAI/Codex 原生安装目录；无需修改系统 PATH 或重新安装 CLI。默认只读、计划审批、独立写入 Worktree 与补丁审批边界保持。

## 验证范围

功能基线来自本机已验证的 `1.0.0-local.1`：Codex / DSH 真实成功、恢复和取消，真实双 Worker 工作流、暂停/恢复、独立审查与有限返工、会议、本地 Ollama 模型规划/审查、SQLite 持久化和重启无重放均有本机运行证据。自用候选版已实测从旧安装覆盖升级、实际用户库 v3→v7、原记录保留和升级前备份一致性。

本次 beta 仅更新发布版本标识与面向发布的文档，不更改上述功能逻辑。历史自用版的真实模型结果不冒充 beta 重新执行结果。发布不改写本机现有自用版安装。

本次 beta 独立验证：

- TypeScript、Lint、生产构建通过；246 项离线测试通过，6 项原生测试默认跳过。

- 仅 Windows User/Machine PATH 启动的新生产 EXE 验证版本、诊断版本、Codex 原生登录及界面连接状态通过；本次未发送模型请求。

## 已知限制

- Windows x64，安装包未签名；不捆绑 CLI、模型、账号或自动更新。请核对同一 Release 的 `SHA256SUMS.txt`。
- WorkBuddy MCP 桥接仍需用户首次信任、手动启动对话和重启后刷新；原生长任务、自动重连、审批与用量未完整验收。
- Antigravity 保留人工交接；DSH 保持只读。外部 Model Provider / OurFreeModel 网关未现场验收，本地小模型可能因目标复杂度失败。
- 原生 Provider 可能超时或受额度限制；未知任务不会自动重跑。真实任务会使用所选 Provider 的服务与额度。
- 卸载现场流程未运行；回退旧版须先保存当前数据并恢复升级前数据库，不能让旧程序直接读取 v7 数据。
